## 方法和操作框架
优先研究“方向确认后买入近平值单腿”，而不是靠便宜权利金赌末日。上涨观察call，下跌观察put；没有方向就不交易。规则是研究假设，尚未经过历史逐笔/分钟回测、样本外验证或含交易成本的实盘验证，不声称盈利优势。

临近到期的近平值期权gamma更敏感，但时间价值也可能迅速衰减；方向判断正确，若变动太慢、幅度不够或隐含波动率下降，买方仍可亏损。低权利金不等于便宜，高gamma不等于正期望。相关教育资料：https://www.cmegroup.com/content/dam/cmegroup/education/files/speculative-strategies-with-treasury-options.pdf

1. 先核对确切到期日、当日期货月份和经纪商规则，选择近平值、报价连续且双边深度足够的合约
2. 先形成开盘区间，例如开盘后5分钟，再等待两根连续已结束的1分钟K线同时突破区间上沿加2个期货tick，或跌破下沿减2tick；相对成交量≥1.5是可配置启发式阈值，应由真实历史相同时间段基准算出，不可用全日均量替代
3. 向上只评估买call，向下只评估买put，不同时买两边、不卖裸期权。突破后偏离触发价超过0.3%不追。数值不是已验证最佳参数，不为产生信号而改小门槛
4. 买入成本取实时ask，不能用昨收、结算或mid；只允许限价上限，不输出订单。深度、最小跳动、涨跌停、同一标的月份、行情时间、仓位和账户权限全过门才输出RESEARCH_TRIGGER_ONLY
5. 以整笔权利金×合约乘数×数量+来回手续费计最坏买方风险，而不是止损距离。默认单笔上限净值0.25%，全日亏损加本笔风险≤1%，在险权利金加本笔≤1%；这是保守示例，不是适合每个账户的个性化建议。手续费必须来自真实账户费率。1手超过预算就跳过，不向上取整
6. 标的回落入原区间可作为人工失效退出条件；应同时观察实时bid，止损与平仓成交无法保证。代码只评估入场研究条件，不管理持仓、执行止损或发送提醒
7. 必须在flatten_by前主动平仓并确认已成交、持仓归零，不能只撤单或发出平仓单。默认比当前连续交易段结束/到期交易结束/券商行权截止中最早者提前≥30分钟，距该最早时点不足60分钟不再开仓。这使当前原型只适用于上午第一段与下午较早阶段，不支持夜盘或跨午休持仓。若无法保证退出，放弃交易

不把价差策略自动化：牛市看涨借记价差/熊市看跌借记价差可作为第二阶段研究，但需同标的同到期、同步双腿买卖盘、各腿费用、组合下单能力和提前指派控制。美式短腿可能提前被行权，理论到期损益图不等于全程无额外期货风险。当前实现只支持单腿买方研究，避免无组合执行保障时逐腿造成裸露风险。

## 行权风险与资料
SHFE/INE这组商品期权为美式。15:00后停止期权交易，不等于行权窗口结束。上期所2026规则允许到期日15:00–15:30行权/放弃申请，券商可能更早截止；是否自动行权由标的期货**结算价**与行权价比较决定，不能拿最后成交价替代。行权/被指派形成期货仓位，带来保证金和后续波动风险，持有到期会超出“仅损失权利金”的简化管理假设。无足额资金也不能假设券商必定替你妥善处理。

## 运行
Python 3.10+，依赖见requirements.txt。从仓库根目录运行（历史行情与元数据请使用原始交付包中的对应文件夹）：

```bash
python -m pip install -r options/expiry_scanner/requirements.txt
python -m unittest discover -s options/expiry_scanner/tests -v
python -m options.expiry_scanner.scanner --raw options-results-20261019 --metadata option-metadata-20261019/prepared_metadata_v2.csv --snapshot-date 20261019 --asof 2026-10-20T00:41:00+08:00 --calendar options/expiry_scanner/calendar_20261019_20261130.json --out options-expiry-results-20261020
python -m options.expiry_scanner.scanner --live-json options/expiry_scanner/example_live_SYNTHETIC.json --asof 2026-10-20T09:10:00+08:00 --calendar options/expiry_scanner/calendar_20261019_20261130.json --out synthetic-demo
```

最后一条是合成数据测试，不是真实盘口/信号。不得把示例中的SYNTHETIC_TEST_ONLY来源或布尔确认直接当实盘认证。`example_live_SYNTHETIC.json`列出完整输入字段；每字段必填，时间含UTC偏移，数值须有限，区间须为交易所连续日盘时段。verified字段是调用方必须实际核实的证明约定，并不能阻止恶意调用方谎报；程序不连接行情商/券商，不能自动验证这类外部证明。它只支持SHFE/INE标准日盘，未知交易所/夜盘/日历范围一律拒绝。日历仅2026-10-19至11-30，超范围不猜节假日；新一天需要重取行情、元数据和核对临时公告。

可用`--config config.json`覆盖Config中的阈值；代码验证类型和范围，但改动必须重新回测，不表示获准交易。完整参数、源文件哈希和请求出处在summary.json。`all_contracts.csv`保留排除类别；`watchlist.csv`保留130行观察项；`one_per_underlying_right.csv`每标的方向一行流动性候选。

实现仅复用v2的只读原始行情解析器，筛选、时间处理、风险逻辑和测试独立。原版与v2算法未改；无券商接口、自动交易或利润保证。历史数据、运行结果和日志保留在原始交付包，不纳入源码提交。
